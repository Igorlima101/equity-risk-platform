# EquityRisk Platform

Financial risk management platform built with Java 21 and Spring Boot.

## About

A backend platform designed to simulate financial risk analysis,
credit limits, collateral management and trade validation.

## Technologies

- Java 21
- Spring Boot
- Maven
- PostgreSQL
- Docker
- Git

## Project Status

Under development.

## Architecture

The platform will progressively evolve towards a modular,
event-driven microservices architecture.

## Purpose

Educational and portfolio project focused on backend engineering,
software architecture, automated testing and financial domain concepts.
